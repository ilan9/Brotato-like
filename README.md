# Brotato-like

Deuxième projet réalisé sur **Godot Engine**. Ce jeu est un **Brotato-like** qui reprend les bases du genre tout en y apportant ses propres mécaniques centrées sur la magie et la combinaison d'éléments.

## Principe du jeu

Le joueur incarne un **sorcier** qui doit survivre à des vagues d'ennemis pour accéder à une boutique entre chaque manche. Une fois la boutique atteinte, il est possible d'**acheter de nouveaux sorts** ou de **revendre les siens** pour adapter son équipement et créer des synergies.

## Système de magie

Chaque sort possède trois caractéristiques : un **type**, un **élément** et un **niveau allant de 1 à 5**. La profondeur du jeu repose sur l'expérimentation pour trouver les meilleures interactions et synergies entre ces différents paramètres.

### Les 5 éléments
* **Eau**
* **Feu**
* **Terre**
* **Vent**
* **Foudre**

### Les 4 types de sorts
* **Météore**
* **Projectile**
* **Laser**
* **Aura**
